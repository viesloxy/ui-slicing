Generated UI fails two ways

Why this exists
01
Generic defaults It builds what such a design usually looks like
Inter everywhere · purple→blue gradients · gradient headlines · 3-card icon grids · centered-everything heroes · emoji as feature icons · AI nav & footer · bounce easing
02
Lazy approximation Right structure, wrong numbers
colors that are close, not the color · spacing that "looks about right" · rounded corners everywhere · invented metrics · fonts swapped to favorites · measured 17px normalized to 16

ui‑slicing attacks both with two rules: measure, don't guess — and the reference wins, even when it uses purple, Inter, or three equal cards. Slop is inventing. Matching is the job.

Six steps. One pass.

The workflow

Image in →
index.html out

Analysis, tokens, and the complete runnable file happen in the same response. The user never asks twice.

01
Acquire

Local image or URL — the fetcher pulls Pinterest pins, Dribbble shots, any page via og:image.

python scripts/fetch_reference.py <url>
02
Analyze

Dimensions, DPR, palette with coverage, section boundaries — then the agent reads every zoomed band crop before writing a single line of code.

python scripts/slice_reference.py ref.png --bands
03
Tokens

Exact hex, identified fonts, measured spacing — locked into a token block before any component exists. No inline improvisation mid-build.

04
Build

One section at a time, each checked against its crop immediately. Real text from the reference; placeholders keep the exact aspect ratio and treatment.

05
Verify

Screenshot vs reference: side-by-side, diff heatmap, per-band scores. Fix the worst bands first, repeat until it matches.

python scripts/compare_screens.py ref.png out.png
06
Deliver

One self-contained index.html. Deviations and assumptions reported explicitly — never silently.

Slop is inventing. Not matching.

58 gates, distilled
Fidelity — colors, fonts, spacing within 5% of measured; every section in order; text verbatim.
No injection — nothing enters the build that isn't in the reference.
No invented content — fake metrics and testimonials are slop, always.
Detail parity — input states, focus rings, empty states weigh as much as the hero.
Quality floor — responsive 320–1920, focus-visible, contrast, reduced-motion.
Self-critique — six axes scored before delivery; anything under 3 gets revised.

The reference wins.

If the design uses three equal cards, purple, or a centered hero — replicate it exactly. Those are only "tells" when the AI invents them. Here they are the design. Never silently improve the reference.
