Turn any screenshot into pixel-perfect front-end code.

Give an AI one image — a Pinterest pin, a Dribbble shot, a SaaS page. ui‑slicing measures it, extracts the tokens, and rebuilds it faithfully. No generic defaults. No invented numbers.

Generated UI fails two ways.

Both come from the same root: the model builds from memory instead of from the image in front of it.

Generic defaults

It builds what such a design usually looks like — not what this image shows.

Inter everywherepurple gradients3-card gridscentered-everything heroesemoji iconstemplate navbounce easing

Lazy approximation

Right structure, wrong numbers — "close enough" instead of the color on screen.

close, not the color"looks about right" spacingone radius on everythinginvented metricsfonts swapped17px normalized to 16

ui‑slicing attacks both with two rules: measure, don't guess — and the reference wins, even when it uses purple, Inter, or three equal cards. Slop is inventing. Matching is the job.

Six steps. One pass.

Image in — index.html out. Analysis, tokens, and the complete runnable file happen in the same response. The user never asks twice.

1

Acquire

Local image or URL — the fetcher pulls Pinterest pins, Dribbble shots, any page via og:image.

python scripts/fetch_reference.py <url>
2

Analyze

Dimensions, DPR, palette coverage, section boundaries — then the agent reads every zoomed band crop before writing a line of code.

python scripts/slice_reference.py ref.png --bands
3

Tokens

Exact hex, identified fonts, measured spacing — locked into a token block before any component exists.

4

Build

One section at a time, each checked against its crop immediately. Placeholders keep exact aspect and treatment.

5

Verify

Screenshot vs reference: side-by-side, diff heatmap, per-band scores. Fix the worst bands first. Repeat.

python scripts/compare_screens.py ref.png out.png
6

Deliver

One self-contained index.html. Deviations and assumptions reported explicitly — never silently.

The reference wins.

If the design uses three equal cards, purple, or a centered hero — replicate it exactly. Those are only "tells" when the AI invents them. Here they are the design. Never silently improve the reference.
